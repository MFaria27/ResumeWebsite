# Resume Website

Source for [mattheusfaria.com](https://mattheusfaria.com), a personal resume and portfolio site built with SvelteKit and Bulma.

## Branches

- `main`: source code (this branch)
- `gh-pages`: built static output served by GitHub Pages. It is generated by `npm run deploy`, so don't edit it by hand.

## Development

```bash
npm install
npm run dev
```

## Styling

Bulma is customized in `static/scss/bulma.scss`. After editing it, regenerate the compiled stylesheet:

```bash
npm run css-build
```

This writes `static/css/bulma.css`, which is committed.

## Adding a project

Copy `src/routes/projects/aaa_template.ts`, fill it in, and register it in `src/routes/projects/aaa_projects.ts`. Thumbnails go in `static/images/project-thumbnails/`.

## Deploying

```bash
npm run deploy
```

This builds the site into `build/` and pushes it to the `gh-pages` branch, which updates the live site. `static/.nojekyll` (which stops GitHub Pages from ignoring the `_app/` folder) and `static/CNAME` (the custom domain) are copied into the build. The `--dotfiles` flag makes sure `.nojekyll` gets published.
